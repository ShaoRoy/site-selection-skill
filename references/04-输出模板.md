# 二、 结构化输出模板

## 🟢 模板 A：商圈初选报告
1. 商圈初判结论　2. 宏观空间分析（干道/地铁枢纽）　3. 下一步行动（建议踏勘主街）

## 🟡 模板 B：现场复核报告
**1. 初筛结论**：`【建议推进去谈租金】` / `【直接放弃】`
**2. 硬件与业态适配**：依 `veto_check` 说明是否触发硬伤
**2.0 数据质量摘要**：原始条数 / 去重后 / 剔除数 / 地理编码失败率 / 坐标系与已知误差来源（见 0.6、0.7）
**2.1 竞品包围（高德）**：注明半径 `{gis_radius}`、关键词、`count`、最近距离、品牌 TOP5
**2.2 腾讯 POI 交叉校验**：同点位同关键词，注明腾讯半径上限 1000m，给出与高德的差异及口径
**2.3 截流预警**：与 `{warning_threshold}` 对比
   - 数据源与圈层：写明「腾讯位置大数据，500m / 1000m」
   - 人口档位：人数绝对值 + 分位档位（高/中/低）+ 参照商圈与参照数
   - 潮汐：日间/夜间均值、T 值、形态判定（全天型/夜间型/时段错配）
   - 主导客群：画像 TOP3 占比、停留时长分布
   - 数据缺失时：写缺失原因 + 标注「待补数」+ 附人工补数清单
**2.5 商务摸底清单**：底价、免租期、物业费、递增、违约金

## 🔴 模板 C：最终投资决策报告
1. 最终投决建议（强烈建议签约 / 需压价至XX元 / 最终否决）
2. 财务测算红线（三档营收/净利、保本日营业额、静态回本、极限租金；注明三个版本号）
3. 商务谈判底牌（硬件缺陷 + 竞品密度 + 人口缺口 + 时段错配 → 施压话术）
4. 最终风险兜底（法律/物业/商圈衰退/人口外流）
5. 免责声明：基于已录入数据、高德 API 与腾讯位置服务返回值生成，仅供决策参考
