# 本地数据位（用户可长期维护）

这里放**你自己调取的官方公开数据**。项目不写爬虫、不主动抓取，更新完全由你决定。

## 为什么要单独放

`data/benchmarks.json` 是「1 列行业基数 × 城市系数缩放」的**估算库**（`data_basis=scaled_estimate`），
不是各城市实测值。以前把实测数据混进去，只能靠 `data_basis_note` 里一段自然语言说明，
机器读不出哪个城市、哪个字段是实测，报告也无法标注来源。这里把实测层独立出来。

> ⚠️ `data/cities.json` 以**广州 = 1.00** 为缩放基数，其他城市按系数推算。
> **不要直接改那个文件的广州数值**——会连带改动其余 19 城。本地数据按城市隔离，只做覆盖，不回写基数。

## 怎么加一个城市

1. 复制 `_template.json` 为 `<城市>.json`（如 `changsha.json`）。
2. 在 `records` 里逐条填；字段含义见模板 `_字段`，可用指标键见 `_可用指标`。
3. 每条必须写 `source` 与 `published_at`；没有链接就把 `source_url` 留空字符串。
4. 示例文件 `guangzhou.json` 里带 `example: true` 的记录**不参与计算**，替换成真实数据后删掉该标记。
5. 跑 `node tools/local-data.mjs --check` 校验结构（CI 也会跑）。

## 取值优先级

| 级别 | 来源 | 报告里怎么标 |
|---|---|---|
| **A** | 本地实测 / 官方公布（本目录） | 「本地数据位 · 来源 X · 发布于 YYYY-Qn（可能滞后）」 |
| **B** | 内置行业基准（benchmarks.json / POI 检索值） | 「行业基准 / 检索值，估算」 |
| **C** | 模型估算 | 「含模型假设，仅供参考」 |
| **D** | 占位默认值 | 「占位值，结论无意义，须补实际值」 |

查不到就逐级回落，报告显示本次实际命中的等级。

## 边界

- **只收官方公开统计与公开市场数据**（统计公报、住建/商务部门公开数据、公开市场报告）。
- **不收自家门店经营数据**。真实经营反馈结构性拿不到，不作为待办或立项依据。
- 官方数据有延后或不准确，但优于猜与估算；因此每条都带 `published_at`，报告如实显示数据年份，不假装实时。
