## 三、端到端测试

### 3.1 白鹅潭万象城（全链路，依赖齐全）

**耗时 2.5 秒**

| 环节 | 结果 |
|---|---|
| 等时圈引擎 | 本地 Valhalla 3.9.1（原生多边形） |
| 内圈·步行10分 | 28 顶点 · 1.09 km² · 圈内 **13 家** |
| 外圈·车行5分 | 204 顶点 · 10.79 km² · 圈内 **77 家**（商圈锁 1500m） |
| 人口核对 | 1 km 密度 **27,348 人/km²**，判定 **机会点** |
| 静态地图 | zoom 14，视口 8.79 × 6.33 km，20 张瓦片内嵌 |
| 报告产出 | `report.html` 525 KB |

**采集告警（4 条，均为数据完整性提醒，非错误）**：
- 缺 `hardware.area_sqm` → 无法判断消防流程复杂度
- 缺 `hardware.needs_exhaust` → 无法判断排烟是否硬性前置
- 腾讯 nearby 上限 1000m → 外圈只有高德数据
- 高德覆盖率 90.2% → 可加 `--sweep` 补齐

### 3.2 杭州湖滨银泰（降级路径）

| 环节 | 结果 |
|---|---|
| 人口核对 | ⚠️ 未执行（栅格还没裁）+ 给补齐命令 |
| 补齐后 | `worldpop-clip.py --city 杭州` 一条命令 |
| 静态地图 | 自动缩放 zoom 17，20 张瓦片内嵌 |
| 报告产出 | `report.html` 387 KB |

**验证点**：缺依赖时不静默、不塞空图、提示具体命令——符合「降级必须留痕」原则。
