### 判断该进哪一筛

**第 2 筛的闸门是「有没有真实租金」，不是筛次。** 租金是现场谈出来的，
有它才说明这单在推进，值得花腾讯配额做双源校验。

**租金判定不许靠眼看**，交给工具：

```bash
python skills/site-selection/scripts/site_core.py rent --text "<用户原话>"
```

它认得 `20000元/月` / `租金20000月` / `2w/月租` / `月租两万` / `租金三万五` /
`一年租金24万`（自动折月）；也认得**不该触发**的：`租金两百五`（三位数）、

## 为什么要改

原表把「我去现场看了」直接映射到第 2 筛。但**现场看过不代表拿到了租金**——
很多情况是看了现场、租金还没谈。

新规则把闸门换成可验证的事实：**有没有能换算成元/月的租金数字**。
这直接影响两件事：

1. 是否启用腾讯双源（腾讯 POI 四接口合计仅 800/日，不能无差别用）
2. 步行距离用哪家（腾讯带 `steps.type` 设施枚举，是决策值；高德只有文本）
