# 证照与环评核查清单（提醒用，不作否决）

> **定位**：这是一张**备忘录**，不是裁决器。
> 资料不齐的铺子本来就签不成、开不了业——工商、消防、环保会先把它拦下。
> 所以系统在这里的职责不是判"能不能开"，而是回答**「还差哪几个数没核」**。

---

## 一、为什么不做成"一票否决"

早期设计里 `veto_check` 会返回 `hard_vetoed: true`，隐含一个错误假设：系统不拦，就会有人签下不合规的铺子。

现实是：**没有排烟、办不出食品经营许可证的位置，走不到签约那一步**。业务链条自己会过滤。

所以本清单的产出必须是：

```
已核实 5 项 ｜ 待核实 3 项 ｜ 不适用 2 项
待核实：环评类别、烟道改造可行性、外立面审批
```

而不是：

```
❌ 硬性否决：无排烟条件
```

---

## 二、通用项（所有餐饮业态）

> **边界先说清**：**营业执照、食品经营许可证由承租方自行办理，与出租方无关，属签约后的行政跟进，不进选址报告。**
> 本清单只核查**场地是否具备办证的前置条件**（排烟、上下水、面积布局、居民距离），不核查"证能不能办下来"——那是租户自己的事，也不该由选址方判断。

| # | 项目 | 核查什么 | 要拿到的东西 |
|---|---|---|---|
| 1 | **场地用途** | 房屋用途是否商业、能否满足餐饮经营的基本条件（不是"能否注册"，注册是租户后续的事） | 产权证 / 租赁合同上的用途栏 |
| 2 | **面积与布局** | 后厨面积占比、生熟分区、更衣间、库房能否满足餐饮布局要求 | 平面图 |
| 3 | **环评类别** | 按《建设项目环境影响评价分类管理名录》判定：报告表 / 登记表（**这是场地属性，取决于规模与位置**） | 当地生态环境局口径确认 |
| 4 | **排烟条件** | 能否接专用烟道、能否上屋顶排放、是否需油烟净化设施 | 物业/业主书面确认 |
| 5 | **上下水与排污** | 隔油池、排污管网接入条件 | 物业确认 |
| 6 | **消防** | 装修改造是否需消防设计备案与竣工验收；疏散宽度、防火分区 | 消防设计图纸审查意见 |
| 7 | **燃气** | 管道燃气报装容量（m³/h）；瓶装气是否受限 | 燃气公司报装确认 |
| 8 | **外立面 / 广告位** | 门头改造、招牌尺寸是否需物业与城管审批 | 物业同意书 |
| 9 | **居民投诉风险** | 是否住宅楼底层、是否紧邻住宅（油烟/噪音投诉高发） | 现场判断 + 周边走访 |

### 不在本清单内的事

| 事项 | 谁负责 | 为什么不进报告 |
|---|---|---|
| 营业执照 | 承租方 | 签约后自行办理，与场地选择无关 |
| 食品经营许可证 | 承租方 | 同上；本清单只核"场地是否满足前置条件" |
| 从业人员健康证 | 承租方 | 开业前内部管理事项 |
| 装修施工许可 | 承租方 / 施工方 | 签约后流程 |

## 三、按业态加项

**大型正餐 / 粤菜酒楼（1000~2000㎡）**
- 环评：面积与灶头数偏大，**报告表**概率高，周期长（1~3 个月），须计入开业计划
- 消防：**≥300㎡ 通常要消防设计备案；≥1000㎡ 多需更严审查**（经验阈值，以当地为准）
- 排烟：大店油烟量大，**独立烟道 + 净化设施**基本是硬要求
- 燃气：明火厨房报装容量大，需提前与燃气公司确认
- 卸货区 / 垃圾房：物业是否提供，影响日常运营

**茶楼（只喝茶吃点心）**
- 蒸煮为主、明火少，排烟压力小于正餐，但仍需蒸汽排放路径
- 早市时段与居民作息重叠，**噪音与客流投诉**风险高于油烟

**中型正餐（80~200㎡）**
- 消防通常按小规模装修处理，但仍需确认是否需要备案
- 排烟常受限于物业既有烟道容量

**茶饮 / 咖啡**
- 主要卡在**上下水**与**外摆许可**，而非排烟
- 部分商场禁止明火与油炸，需确认经营项目范围

**便利店**
- 热食（关东煮、烤肠）需单独确认食品经营许可的经营项目
- 无排烟需求，但需确认用电增容

## 四、怎么用（输出格式）

建档（`profile-build.mjs`）时打印本清单，开发带去现场逐条勾：

```
☐ 场地用途：产权证/租赁合同用途栏是否为商业
☐ 环评类别：报告表 or 登记表（问当地生态环境局）
☐ 排烟：接市政管网 / 独立烟道 / 屋顶排放
☐ 上下水与排污：隔油池、排污管网接入
☐ 消防：是否需设计备案与验收；疏散宽度（≥300㎡ 通常需备案）
☐ 燃气：报装容量 m³/h
☐ 面积与布局：后厨占比、生熟分区、更衣间、库房
☐ 外立面 / 广告位审批
☐ 居民投诉风险（住宅底层 / 紧邻住宅）
☐ 产权：转租、抵押、纠纷
```

**营业执照与食品经营许可证不在此列**——那是承租方签约后自己办的事。

核实结果回填到调研表 `fields`，再由 `veto_check` 按规则包比对——**越界时报告写「待核实/风险提示」，不写「否决」**。

## 五、措辞纪律

| ❌ 不要写 | ✅ 要写 |
|---|---|
| 硬性否决：无排烟 | 排烟条件未核实（影响：无法通过环评） |
| 该铺不可开 | 待核实 3 项，其中环评类别影响开业周期 1~3 个月 |
| 违规风险高 | 居民楼底层，油烟投诉历史需向物业核实 |

**判断留给读的人，系统只负责把缺口列清楚。**
