## 一、scratch-plugin（开发工作区）

| 路径 | 内容 |
|---|---|
| `src\site-tools.ts` | **核心引擎**（5,100+ 行）：6 个工具、财务三档、翻台五档、空间模型、租期现金流 |
| `src\benchmark-data.ts` | 行业基准数据（19 城 × 48 业态，**是缩放估算不是实测**） |
| `tools\*.mjs` | 20 个 Node 脚本：采集、渲染、测试 |
| `tools\*.py` | 7 个 Python 脚本：需求侧、网格、步行矩阵 |
| `profiles\*.json` | 业态档案（5 个：粤菜/茶楼/早餐/两个测试档） |
| `survey\*.csv` | 调研表（含 `扬韬广场-模拟.csv` 和 `扬韬广场-合理基准.csv`） |
| `params\` | 业态参数 + 单店覆盖 |
| `out\` | **运行产物**（probe.json / report.html / tiles 瓦片缓存） |

## 二、dist（打包产物）

### 三包的关系

```
dist\site-selection-skill\      ← 【主包】所有改动先进这里
        ↓ 复制
dist\site-selection\            ← 03 源码包用
dist\wb-expert\skills\site-selection\  ← 02 专家包用
        ↓ 打包
dist\upload\01-skill-导入技能.zip
dist\upload\02-expert-配置专家.zip
dist\upload\03-github-仓库源码.zip
```

| 包 | 用途 | 特殊说明 |
|---|---|---|
| `01-skill` | 导入技能平台 | **不含** `.codebuddy-plugin\`、`agents\`、`avatars\` |
| `02-expert` | 配置专家/角色 | 含上述三项，结构为 `site-selection-analyst\skills\site-selection\` |
| `03-github` | 源码仓库镜像 | 完整，含 `.github\` |

`dist\upload\release\` 是版本化副本（`site-selection-*-v2.10.13.zip`），专供 GitHub Release 上传，**不是重复文件**。

## 三、.dsh（本地 DSH 安装）

```
.dsh\skills\site-report\
├─ SKILL.md          （65 KB，与 dist 的 SKILL.md 逐字节一致）
└─ params\           （grid / large_yuecai / tea_house / _template + README）
```

**这是精简安装**：只有技能文档 + 参数，引擎由 DSH 插件从 `scratch-plugin` 加载。
不要指望在这里找到 `dsh\site-tools.ts`。

## 六、密钥

```
C:\Users\<你>\.dsh\secrets\
├─ amap.key      （高德，可含 # 注释行，脚本会跳过）
└─ tencent.key   （腾讯）
```

4 个脚本都按「环境变量 → 该目录」顺序读，都会跳过注释行。
也可用环境变量 `AMAP_API_KEY` / `TENCENT_MAP_KEY` 覆盖。
