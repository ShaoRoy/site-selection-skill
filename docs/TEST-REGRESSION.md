## 五、WorldPop 人口核对冒烟（E1）

不写自动化套件，跑一次确认三件事：**能出数 / 偏移标注在 / 不报错**。

```powershell
"D:\QGIS 3.44.8\bin\python-qgis-ltr.bat" tools/worldpop-sample.py `
  --tif ../data/worldpop/gz_pop_2020_100m.tif --center "23.124734,113.244246" --out pop.json
```

扬韬广场实测输出：

```
GCJ→WGS 偏移 620m
500m  → 51,887 人 ｜ 66,064 人/km²
1000m → 198,259 人 ｜ 63,108 人/km²
3000m → 1,190,567 人 ｜ 42,108 人/km²
三圈 in_raster 全部 true
```

**判据**：偏移必须是 **620m 左右**（GCJ-02→WGS84 在华南的固定偏差）；若接近 0 说明没做坐标转换，500m 圈会偏 600 米，结论全错。

## 八、易错点备忘（都踩过）

| 坑 | 症状 | 判据 |
|---|---|---|
| `arg()` 默认值是 `null` 不是 undefined | 用 !== undefined 判参数是否传入 → 永远成立 → 默认路径变成 <cwd>/null，**底图全丢且不报错** | 跑一次不传 --tiles 的 render-static-map，看「N 张命中」是否 > 0 |
| 瓦片目录约定 | `tiles/` 是 **probe 所在目录的兄弟**，不是 probe 的兄弟：out/点位/probe.json → out/tiles/ | 同上 |
| 自动缩放会换 zoom | 同一份数据，圈层跨度一变，zoom 从 16 变 17，缓存里没这层就等于没图 | 看「瓦片 N 张命中」是否为 0 |
| CSV 编码 | GBK/UTF-16 整表解析为空**不报错** | 财务参数是否全回落默认值 |
| 业态码来源 | 从调研表 meta.format_code 读，**不是**从 profiles 读 | 只换档案不换表 → 业务判读完全不变 |
